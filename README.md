PAGAM-IA
“Plataforma Web de Gestión de Activos Tecnológicos y Mantenimiento Predictivo con Inteligencia Artificial”

Descripción del Proyecto:
Sistema web integral orientado a la administración centralizada del inventario tecnológico corporativo, la gestión de licencias de software y la predicción proactiva de fallas en equipos mediante modelos de Inteligencia Artificial y telemetría.
